Click the button to view a PDF document generated by JavaScript PDF Library. Please note that Adobe Reader or its equivalent is required to view the resultant document.

This sample demonstrates adding layers (Optional Content Group) with different shapes in the PDF document. The Syncfusion JavaScript PDF library also supports creating, merging, and toggling the layers.

This feature can be used in CAD drawings, maps, layered artworks, and multi-language documents. More information about the layers can be found in this documentation section.
